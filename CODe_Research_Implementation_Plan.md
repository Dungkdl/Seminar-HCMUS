# ClinDistill — kế hoạch và protocol hiện hành

**Đọc [protocol nghiên cứu 0.6.0](Khóa%20luận/_support/RESEARCH_PROTOCOL.md)**: định nghĩa cohort/task, visual → clinical → transfer, công thức OOF/KD, thống kê và điều kiện review. Tài liệu này cũng đi kèm source bundle để hướng dẫn trên Kaggle không phụ thuộc file ngoài gói.

Implementation hiện hành: CODe photo-only, sáu recorded targets, DINOv3/BGE-M3 frozen; học MIL/projection/fusion/head. Không có healthy class hoặc full pretrained training/test results được xác minh trong repo. Annotation/clinical/near-duplicate reviews còn mở.

[Hướng dẫn Kaggle](Khóa%20luận/_support/KAGGLE_RUNBOOK.md), [sơ đồ seminar hiện hành](Seminar.md), [chỉ mục tài liệu](Paper/README.md). [Kế hoạch tháng 10](docs/archive/2026-10-28-research-plan.md) và [poster ban đầu](docs/archive/Seminar-original.png) chỉ được giữ làm lịch sử.

Theo dõi tại [Issue #5](https://github.com/Dungkdl/Seminar-HCMUS/issues/5); umbrella [#1](https://github.com/Dungkdl/Seminar-HCMUS/issues/1) và xác nhận runtime [#4](https://github.com/Dungkdl/Seminar-HCMUS/issues/4) vẫn mở.
